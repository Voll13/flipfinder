# FlipFinder v1.0.0 — First Public Release

## Highlights

FlipFinder is an open-source marketplace opportunity intelligence platform. v1 focuses on iPhone deals on OLX Poland.

## Core engine

The engine collects ordinary browser HTML, normalizes listings, retains a 72-hour market universe, builds exact comparables, ranks candidates before AI, estimates deterministic resale, and scores profitability.

## Web Admin

The local Control Center provides a RU/PL dashboard, monitoring controls, settings, manual review, favorites, notes, comparison, market history, and trend views.

## Telegram

Alerts are sent only for genuine flip candidates. Fixed labels and presentation-only AI free-text support Russian and Polish. Translation failures safely fall back to canonical text.

## Market intelligence

Benchmarks use recent comparable market observations by model, storage, and condition. Deterministic resale is separated from advisory AI estimates.

## Languages

Web Admin and Telegram report language are independent. Telegram supports Russian and Polish.

## Safety

No CAPTCHA solving, stealth evasion, proxy bypass, cookie theft, or challenge loops are implemented. AI output is advisory and users must verify each deal independently.

## Known limitations

- OLX Poland only in v1.
- iPhone-focused product profile.
- The local machine must stay running while monitoring.
- An AI provider is required for semantic analysis.
- Marketplace HTML and embedded state may change.
