# Contributing to FlipFinder

1. Fork the project and create a focused branch.
2. Keep changes small, documented, and covered by meaningful tests.
3. Run `python -m compileall app` and `pytest -q` before opening a pull request.
4. Explain the user-visible effect and validation in the PR.

Never commit credentials, local databases, logs, browser profiles, cookies, screenshots with private data, or `.env` files.

Contributions must not add CAPTCHA solving, stealth/fingerprint evasion, proxy bypass, cookie theft, or other anti-bot bypass behavior. Preserve the existing safety rules and do not weaken scoring or notification safeguards without a focused, reviewed rationale.
